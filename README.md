Project in development phase. Phases 1-3 of MVP completed.

Python 3.12, Playwright, BeautifulSoup4, Pydantic v2, Loguru, RapidFuzz, Tenacity, httpx, Ollama + Gemma 4 31B cloud (via local proxy), SQLite.
