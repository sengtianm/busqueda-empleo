# Anexo 5C - Plantillas oficiales del proyecto

El presente anexo establece las plantillas oficiales que deberán utilizarse para la elaboración de la documentación perteneciente a la automatización de búsqueda de empleo.

Su propósito es garantizar uniformidad, consistencia y facilidad de mantenimiento en todos los documentos oficiales del proyecto.

Las plantillas aquí definidas constituyen el formato de referencia para la creación de nueva documentación.

---

# C.1. Plantilla para documentos normativos

```markdown
# Nombre del documento

## 1. Propósito del documento

## 2. Principios

## 3. Definiciones generales

## 4. Desarrollo del contenido

## 5. Restricciones

## 6. Criterios de aceptación

## 7. Referencias

## 8. Índice
```

Aplicable a documentos como:

* Estándares.
* Arquitectura.
* Modelo de Datos.
* Seguridad.
* Manejo de Errores.

---

# C.2. Plantilla para capítulos

Cada capítulo deberá mantener la siguiente estructura:

```markdown
# Nombre del capítulo

Introducción.

---

### COD-001. Nombre de la regla

Descripción.

---

### COD-002. Nombre de la regla

Descripción.

...

---

## Principios generales

- Principio 1
- Principio 2
- Principio 3
```

---

# C.3. Plantilla para reglas

---

# C.14. Principios de las plantillas

Todas las plantillas oficiales deberán cumplir los siguientes principios:

* Uniformidad.
* Claridad.
* Reutilización.
* Consistencia.
* Escalabilidad.
* Mantenibilidad.
* Trazabilidad.
* Compatibilidad con el resto de la documentación.

---

# C.15. Fuente oficial

Las plantillas definidas en el presente anexo constituyen el formato oficial para la elaboración de toda la documentación perteneciente a la automatización de búsqueda de empleo.

Cualquier nueva plantilla deberá mantener compatibilidad con las estructuras aquí establecidas.
